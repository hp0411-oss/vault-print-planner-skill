## Short English post

I made a free, open-source local planner for my USSA VAULT storage builds. Choose drawers or accessories, preview the combination, review source files and hardware, and export a 3MF project for the selected supported Bambu machine for Bambu Studio. English + Chinese; optional Codex skill, but the website also runs on its own.

Based on marcelfarres/vault-configurator (AGPL-3.0), with a bilingual planner workflow, accessory-only selection and progress records.

Looking for 3–5 VAULT owners to try installation and the first export—especially on Windows/Linux. macOS has been smoke-tested. Purchased models are required and are not included. You still check and slice in Studio before printing.

Demo, download and setup: https://github.com/hp0411-oss/vault-print-planner-skill

## Where and how to share

1. Start with an existing VAULT owner community or the creator's community, if it permits third-party tools. Ask the moderator when the rules are unclear.
2. Use your own social account for the demo and a personal explanation of the problem it solves.
3. Check each community's current self-promotion rules before posting. Do not mass-post identical text or imply endorsement by VAULT / Bambu Lab.
4. Ask for specific installation/export feedback; avoid asking for stars as a condition of help.
5. Keep a small record of channel, date, feedback and fixes. Never publish testers' personal details without permission.

## First feedback round

Target: 3–5 volunteer testers. Useful outcomes: a clean installation, an identified parts list, a project opening in Studio, and a reproducible issue when something fails. Downloads do not prove successful installs; stars do not prove successful prints.

After fixes, publish a new version with concrete changes and verified platforms. Keep v0.1.0's original artifact intact.

### Draft community introduction — use only where permitted

I'm a VAULT user looking for a few people to try a bilingual planning workflow. This is an unofficial extension based on marcelfarres/vault-configurator (credit to the original project), adding English/Chinese switching, accessory-only selection, saved-task recovery and print-progress records.

It is free/open source, runs locally, and requires your own purchased VAULT archive. No paid model files are distributed. The current main-branch package reads installed single-nozzle Bambu profiles (0.4/0.6 mm, PLA/PETG); dual-nozzle machines are not supported yet; macOS has been smoke-tested and Windows/Linux feedback would help. You don't need to do a physical print to test installation and opening an exported 3MF in Studio.

Demo, download and limitations: https://github.com/hp0411-oss/vault-print-planner-skill

If you try it, please share where setup gets confusing or open an issue. Please don't upload purchased models in feedback.
